## Документация

[Каталог руководств](Docs/README.md) содержит документацию по интерфейсу, данным, режимам, тестам и обновлению VBA. Начните с [DSL Word/Movement](Docs/PersonalEventBuilder-TemplateDSL.md), если нужно настроить текстовые шаблоны или группировку PersonalEventBuilder.

## Структура проекта

- `Docs` — руководства по архитектуре и API; у каждой статьи есть содержание и навигация.
- `vba` — общие компоненты и исходники режимов.
- `ui` — XAML-страницы, контролы и стили.
- `config` — конфигурации режимов и окружений.
- `workbook` — книги режимов, шаблоны и источники.
- `tests` — сценарии, ожидания и тестовые зависимости.
- `WorkbookUpdater` — обновлятор модулей и его инструменты.

В корне проекта остаётся один Markdown-файл — этот README. Руководства находятся в Docs; локальные README тестов, режима генерации периодов и обновлятора остаются рядом со своими компонентами и доступны из общего каталога.
