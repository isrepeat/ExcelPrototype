# Инструменты командной строки для Excel

Инструменты — отдельные исполняемые приложения с общими библиотеками .NET Framework. Сборка выполняется через `Compile*.cmd` штатным 64-разрядным компилятором Windows .NET Framework. .NET SDK и MSBuild для этого не нужны. Файл `ExcelTools.sln` и классические `.csproj` описывают проекты для работы в IDE.

## Общие библиотеки

| Проект | Назначение |
| --- | --- |
| common/Tooling | Разрешение путей относительно заданного каталога, имена временных файлов и публикация результата с восстановлением предыдущего файла |
| common/Tooling.Console | Вывод в UTF-8, статус выполнения, время работы, журнал исключений и интерактивная пауза |
| common/Excel.Tables | Описание выбранных книг и листов без зависимости от COM |
| common/Excel.Interop | Отдельные сеансы Excel, освобождение COM-объектов и подготовка значений ошибок Excel к записи |

Каждый инструмент ссылается на общие проекты; общие библиотеки не зависят от инструментов. Конфигурация конкретного инструмента, алгоритмы и форматирование результата остаются в его проекте. Модель снимка таблицы и контракты чтения можно добавить, когда они понадобятся инструменту. Сравнение таблиц и формирование HTML-отчётов пока не реализованы.

`ExcelSession` владеет COM-объектами `Application` и `Workbooks`. Вызывающий код отвечает за открытые или созданные книги: закрывает их без сохранения нежелательных изменений и освобождает собственные COM-объекты перед заключительной сборкой мусора. Режим вычислений задаётся вызывающим кодом после создания или открытия книги. Сеанс отключает предупреждения, обновление экрана, события и макросы; обновление данных и пересчёт источников не запрашиваются.

## Сборка и развёртывание

Запустите `Agregator/CompileAgregator.cmd`, чтобы собрать агрегатор и его библиотеки. Скрипт `common/CompileCommon.cmd` принимает явно заданный каталог результата, при ошибке возвращает ненулевой код завершения и не делает паузу. Агрегатор сначала собирает все файлы в `Agregator/build/.staging`, затем публикует EXE и DLL в `Agregator/build`. В корне агрегатора из файлов остаётся только `CompileAgregator.cmd`; исходники находятся в `sources`, конфигурации — в `resources`. Созданные бинарные файлы и каталоги проектов `bin/obj` исключены из Git.

Развёртывайте каталог `build` с исполняемым файлом и всеми четырьмя `ExcelTools.*.dll` вместе с соседним каталогом `resources`, содержащим конфигурации. Имя конфигурации ищется рядом с EXE, затем в `resources` рядом с EXE, затем в `resources` родительского каталога. Явно заданный путь используется без поиска альтернатив. Для повторной сборки нужны общие исходники; для запуска развёрнутого инструмента они не требуются. Замена результата использует переименование в одном каталоге и восстановление предыдущего файла, сохраняя совместимость с существующим сценарием работы через SMB. Развёртывание нескольких бинарных файлов не является атомарной операцией: перед заменой закройте работающие инструменты.

Агрегатор сохраняет существующую конфигурацию, аргументы и три режима копирования. Его исходники разделены на точку входа CLI, чтение конфигурации, службу агрегации и обработку XML-стилей. Инструмент сравнения в состав не входит.
