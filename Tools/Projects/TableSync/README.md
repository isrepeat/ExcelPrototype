# TableSync

Необязательный атрибут `compareIgnorePattern` у `field` задаёт регулярное выражение. Перед сравнением из обоих значений удаляются совпадения с шаблоном. Правило влияет на отбор предложений. При реальном различии в отчёте и при записи используется исходное значение из ШПО. В профиле `Movement` правило для ФИО игнорирует конечный десятизначный ІПН в скобках.

TableSync сравнивает источник и целевую книгу `.xlsx` и переносит одобренные текстовые значения в отдельную копию целевой книги.

## Запуск

После сборки запустите `build\TableSync.exe` двойным щелчком. Из каталога TableSync в PowerShell:

```powershell
.\CompileTableSync.cmd
.\build\TableSync.exe
```

При запуске без аргументов программа ищет `TableSync.xml` относительно EXE, в том числе в соседнем каталоге `resources`. Она выбирает профиль с `default="true"` или единственный профиль, если отметка отсутствует. Для разового запуска с другим профилем укажите путь к XML и имя профиля двумя аргументами.

Перед запуском настройте профиль в `resources/TableSync.xml`. Относительные пути отсчитываются от каталога XML. Профиль `Movement` связывает «ОС» в ШПО с листом «Список» в РУХ. Проверьте точные заголовки и добавьте по одному `mapping` для каждого целевого листа.

При `overwriteTarget="false"` (по умолчанию) инструмент сохраняет копию рядом с целевой книгой. Для `РУХ_last.xlsx` это `РУХ_last (synced).xlsx`. Атрибут `output` позволяет задать другой путь к новой копии. Чтобы записать изменения в исходную целевую книгу, установите `overwriteTarget="true"` и уберите атрибут `output`.

Задайте ключи в `sourceKey` и `targetKey`. Элементы `field` задают соответствия колонок для переноса. Заголовки и ключи сравниваются точно с учётом регистра. Заголовочная строка определяется по набору настроенных колонок. Если этот набор встречается несколько раз, укажите `sourceHeaderRow` или `targetHeaderRow`. Для ограничения диапазона данных есть `sourceLastRow` и `targetLastRow`.

Если ключ не найден в источнике, опциональные `sourceFallback` и `targetFallback` разрешают предложить пару по совпадающему уникальному значению, например ФИО. Для этого оба ключа должны быть заполнены и уникальны, а новый ключ должен отсутствовать в целевом диапазоне. Колонку ключа нужно включить в `field`. Если изменились и ключ, и резервное поле, пара требует ручной сверки.

До подтверждения открывается отчёт TableDiff `(sync preview).diff.html`. Проверьте весь список и введите в консоли `y` или `yes`, чтобы применить все предложения. Регистр букв не учитывается. Enter без текста и любой другой ввод отменяют запись. После применения открывается `(sync applied).diff.html` с фактическими изменениями между исходной и результирующей книгами. Отчёты сохраняются в каталоге результата.

В `externalTools/tool` укажите путь `executable` к TableDiff.exe. TableSync запускает этот файл отдельным процессом. Атрибуты `previewDiff` и `appliedDiff` выбирают профили из вложенного блока `<tableDiff>`, который использует обычный синтаксис TableDiff. Пути считаются относительно каталога `TableSync.xml`. Пары книг и листов должны соответствовать настройкам синхронизации. При смене пути результата обновите `new/@file` в профиле второго отчёта. При записи в исходную книгу укажите этот путь и в `old`, и в `new`.

TableSync использует эти профили для оформления отчётов с предложениями и с фактическими изменениями. Самостоятельный `TableDiff.exe --config <путь к TableSync.xml> --profile MovementPreview` выполнит обычное сравнение книг по этому профилю. При таком запуске XML должен содержать один вложенный блок `<tableDiff>`.

Оба инструмента используют `ExcelTools.Excel.Changes.dll` из `Tools/common`. TableSync передаёт предложения внешнему TableDiff во временном XML версии 1. Для итогового отчёта TableDiff сам сравнивает исходную книгу с подготовленной копией по номерам строк. Сборка TableSync размещает общие DLL рядом с `TableSync.exe`, а TableDiff запускается из каталога, указанного в `executable`.

Пустые значения источника и формулы пропускаются. Новые значения записываются как текст, в том числе ІПН с ведущими нулями. Производные колонки вроде УІД обновятся при открытии результата в Excel, если они вычисляются формулами.
